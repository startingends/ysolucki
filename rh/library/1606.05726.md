Conventions: `s = 1/2 - iz`; `F^sharp(z) = conj F(conj z)`; `xi_L(s) = s^{m_L}(s-1)^{m_L} Lambda_L(s)` (for zeta,
`xi(s) = (1/2)s(s-1)pi^{-s/2}Gamma(s/2)zeta(s)` in the introduction). `HB-bar` = entire `E` with
`|E^sharp(z)| < |E(z)|` on the upper half-plane; `HB` = those with no real zeros. For `E in HB-bar`,
`A = (E + E^sharp)/2` and `B = i(E - E^sharp)/2` have only real zeros. `S_R` = functions `L != 1` of the Selberg
class with `L(R) subset R` and `Lambda_L(R) subset R`. `d_L` = degree. Fourier: `(Ff)(z) = int f(x) e^{ixz} dx`.
Two parameters: a shift `omega > 0` and a power `nu` (positive integer):
`E_L^{omega,nu}(z) := xi_L(1/2 + omega - iz)^nu`,
`Theta_L^{omega,nu}(z) := (E^sharp/E)(z) = eps_L^nu xi_L(1/2 - omega - iz)^nu / xi_L(1/2 + omega - iz)^nu`.
The variable `t >= 0` of the canonical system is a third, separate parameter (a half-line cut-off).

## 2. Main theorems
- **Proposition 2.1.** "For L in S_R, GRH(L) holds if E_L^{omega,1} in HB-bar for all omega > 0."
- **Proposition 2.2** (unconditional for `omega > 1/2`). "E_L^{omega,nu} belongs to HB for every omega > 1/2
  unconditionally and for every 0 < omega <= 1/2 under GRH(L)." (Proof: Lagarias-Suzuki 2006, Theorem 4, applied
  to `xi_L^nu`, which has its zeros in the strip and satisfies the functional equations.)
- **Proposition 4.3.** For `omega_0 >= 0` the following are equivalent: (1) `L(s) != 0` for `Re s > 1/2 + omega_0`;
  (2) `E_L^{omega,nu} in HB` for every `omega > omega_0`; (3) `Theta_L^{omega,nu}` is a meromorphic inner function in
  the upper half-plane for every `omega > omega_0`. "The value of nu does not affect the above equivalence."
- **The kernel** (2.6)-(2.7), Proposition 4.1. `K_L^{omega,nu}` := inverse Fourier transform of `Theta_L^{omega,nu}`
  along a high horizontal line. It vanishes on `x < 0` and for `x > 0`
  `K_L^{omega,nu}(x) = eps_L^nu sum_{n <= e^x} q_L^{omega,nu}(n) n^{-1/2} G_L^{omega,nu}(x - log n)`, where
  `sum q(n) n^{-s} = (L(s-omega)/L(s+omega))^nu`, i.e. `q_L^{omega,nu}(n) = n^omega sum_{d|n} a_L^nu(n/d)
  a_L^{-nu}(d) d^{-2 omega}` (a multiplicative function on ALL integers, not only prime powers), and `G` is an
  explicit function supported on `[0, inf)` built from the gamma factor and the pole factor. If
  `nu omega d_L > 1` (condition (2.8)), `K` is continuous, `O(e^{c|x|})`, with locally integrable derivative;
  if `nu omega d_L > k + 1` it is `C^k`.
- **Theorem 2.1** (unconditional). "Let L in S_R and (omega, nu) be such that (2.8) holds. Then, for every t > 0,
  [K[t] f(x) := 1_{(-inf,t)}(x) int_{-inf}^t K(x+y) f(y) dy] defines a Hilbert-Schmidt type self-adjoint operator
  on L^2(-inf,t) having a continuous kernel, and K[t] = 0 for t <= 0. Moreover, there exists
  tau = tau(L; omega, nu) > 0 such that both ±1 are not the eigenvalues of K[t] for every t in [0, tau). In
  particular, the Fredholm determinant det(1 ± K[t]) does not vanish for every t in [0, tau)." Only the values
  of `K` on `[0, 2t)` enter: the gamma factor and the finitely many `q(n)` with `n < e^{2t}`.
- **Hamiltonian** (2.10): `H_L^{omega,nu}(t) := diag(1/gamma(t), gamma(t))`,
  `gamma(t) := (det(1 + K[t]) / det(1 - K[t]))^2`.
- **Theorem 2.2** (unconditional, on `[0, tau)`). With `phi^±(t,x)` the solutions of `(1 ± K[t]) phi = K(x+t)`
  extended to `R`, the functions (2.12)
  `A(t,z) := (1/2) gamma(t)^{1/2} E(z)(e^{izt} + int_t^inf phi^+(t,x) e^{izx} dx)`,
  `-iB(t,z) := (1/2) gamma(t)^{-1/2} E(z)(e^{izt} - int_t^inf phi^-(t,x) e^{izx} dx)` extend to real entire
  functions of `z` (even, resp. odd), solve the canonical system
  `-d/dt [A; B] = z [0 -1; 1 0] H(t) [A; B]` on `[0, tau)`, and `A(0,z) - iB(0,z) = E_L^{omega,nu}(z)`.
- **Proposition 5.1** (if `E_L^{omega,nu} in HB-bar`; hence unconditional for `omega > 1/2`). For every `t >= 0`:
  `||K[t] f|| != ||f||` for `f != 0`, and `||K[t]|| < 1`; "In particular, 1 ± K[t] are invertible operators on
  L^2(-inf,t) for every t >= 0." So then `tau = inf`.
- **Theorem 2.3.** Under (2.8), and assuming `E_L^{omega,nu} in HB-bar` if `0 < omega <= 1/2`: with
  `J(t;z,w) := (conj A(t,z) B(t,w) - A(t,w) conj B(t,z)) / (pi (w - conj z))`, "J(t;z,z) is not identically 0 as a
  function of z for any t >= 0 and lim_{t -> inf} J(t;z,w) = 0 for every fixed z, w in C."
- **Theorem 2.4** (the equivalence). "The validity of GRH(L) for L in S_R is equivalent to the condition that
  there exists a sequence (omega_n, nu_n) in R_{>0} x Z_{>0}, n >= 1, such that (1) omega_m < omega_n if m > n
  and omega_n -> 0 as n -> inf, (2) nu_n omega_n d_L > 1, (3) det(1 ± K_L^{omega_n,nu_n}[t]) != 0 for every
  t >= 0, and (4) lim_{t -> inf} J_L^{omega_n,nu_n}(t;z,z) = 0 for every z in C_+."
- **Theorem 6.1** (variant). For `0 < omega_0 < 1/2`: `L(s) != 0` for `Re s > 1/2 + omega_0` iff the same four
  conditions hold along a sequence `omega_n` decreasing to `omega_0`.
- **Theorem 7.1.** If `E_L^{omega,nu} in HB-bar`, multiplication by `z` has dense domain in the de Branges space
  `B(E_L^{omega,nu})`. Consequence drawn in section 7 (from Kaltenbaeck-Woracek): its self-adjoint extensions
  `M_theta`, transported to `D_theta` (acting as `i d/dx` up to domain) on a space `V_0 subset L^2(0, inf)`
  isomorphic to `L^2(0,inf)/K(L^2(-inf,0))`, have as eigenvalues exactly the zeros of `A_L^{omega,nu}`
  (`theta = pi/2`) or of `B_L^{omega,nu}` (`theta = 0`), with eigenfunctions
  `f_{theta,gamma}(x) = e^{-i gamma x}(1_{[0,inf)}(x) - e^{-2i theta} int_0^x K(y) e^{i gamma y} dy)`.
  Unconditional for `omega > 1/2`; under GRH(L) for `0 < omega <= 1/2`.

## 3. Method in ten lines
1. RH for `xi` is equivalent to `xi(1/2 + omega - iz)` being of Hermite-Biehler type for every shift `omega > 0`
   (a zero-free half-plane statement); powers `nu` do not change this.
2. For `omega > 1/2` this holds unconditionally (zeros lie in the closed strip).
3. De Branges: each `E in HB-bar` comes from a canonical system; conversely a canonical system on `[0, t_1)` with
   `J(t;z,z) -> 0` as `t -> t_1` produces `E(t, .) in HB-bar`.
4. The inverse problem is solved by a recipe ([Su19], after Burnol): take `K` = inverse Fourier transform of
   `E^sharp/E`, supported on the half-line; form the truncated Hankel-type operators `K[t]` (kernel `K(x+y)` on
   `(-inf, t)`); as long as `±1` are not eigenvalues, `gamma(t) = (det(1+K[t])/det(1-K[t]))^2` gives a diagonal
   Hamiltonian of determinant one and the solution is written with the resolvents.
5. The recipe needs `K` continuous; for small `omega` the transform of `xi(s-omega)/xi(s+omega)` decays only like
   `|u|^{-omega d_L}`, so the paper raises to a power `nu` with `nu omega d_L > 1`. This is the new device.
6. `K` is explicit: Dirichlet coefficients of `(L(s-omega)/L(s+omega))^nu` at all `n <= e^x`, smoothed by an
   archimedean function (Mellin-Barnes type formula for ratios of gamma functions).
7. For small `t`, `1 ± K[t]` is invertible unconditionally (a weighted `L^2` comparison using decay of `Theta`
   high in the half-plane).
8. If `Theta` is inner (i.e. `E in HB-bar`), `K` is an isometry of `L^2(R)`, and `||K[t]|| < 1` for all `t` because a
   norm-attaining `f` would give a compactly supported function whose transform has `>> T log T` zeros.
9. Then [Su19, Thm 1.2] gives `J -> 0` (necessity); [Su19, Prop. 2.4] gives sufficiency.
10. The work of this paper is in steps 5 to 8; steps 3, 4, 9 are imported.

## 4. What is assumed
- Theorems 2.1, 2.2, Proposition 2.2, Proposition 4.3, and everything for `omega > 1/2`: unconditional.
- Proposition 5.1, Theorem 2.3, Theorem 7.1 for `0 < omega <= 1/2`: assume `E_L^{omega,nu} in HB-bar` (true under
  GRH(L); equivalent to a zero-free half-plane by Prop. 4.3).
- Class: `S_R` (real Dirichlet series with real completed function), so `eps_L = ±1`. Remark (1): only a
  polynomial bound on `a_L(n)` is used, "the Ramanujan conjecture (S4) is not necessary". Remark (2): "the
  Euler product (S5) is essential to the construction ... the explicit formula of the kernel K coming from (S5)
  was critical to prove that E satisfies (K2) and (K3). It seems that it is not easy even to prove that K is a
  function if we do not have (S5)."
- The inverse-problem theorems of [Su19] (not read here).

## 5. Where its frontier is
**Last things proved.** (i) Unconditionally: for every `(omega, nu)` with `nu omega d_L > 1` a Hamiltonian and a
solution reproducing `xi_L(1/2 + omega - iz)^nu` exist on SOME interval `[0, tau)`, `tau > 0` not quantified
(Thm 2.1, 2.2); for `omega > 1/2` they exist on `[0, inf)` with `J -> 0`. (ii) The equivalence of Theorem 2.4.

**First things it cannot do.**
- Extend the Hamiltonian beyond the unspecified `tau` for any `omega <= 1/2` without assuming the zero-free
  half-plane: no value `omega_0 < 1/2` is reached unconditionally (`omega = 1/2` "comes from the trivial zero-free
  region").
- Decide whether condition (3) (non-vanishing determinants for all `t`, i.e. the Hamiltonian exists on the whole
  half-line) already implies condition (4) (`J -> 0` at infinity). The theorem needs both. Remark (5): "we do
  not know the role of the behavior of K(x) at x = +inf in the equivalent condition of Theorem 2.4."
  Remark (6): the stronger limit condition (4') is sufficient, "but we have no plausible evidence to support
  the necessity of (4')"; "it is not clear whether lim_{t -> +inf} A(t,z) defines a function of z"; "The limit
  behavior may be related to the arithmetic properties of L(s) in a deep level, because we need information of
  all q(n)'s to understand it differ from the situation that we need only finitely many q(n)'s to understand
  K[t] for a finite range of t. We do not touch this problem further in this paper."
- Work at `omega = 0`: the Hamiltonian `H_L` of `E(z) = xi_L(s) + xi_L'(s)` is called "conjectural"; the family in
  `omega` "may be considered as a perturbation" of it, with `nu(omega) -> inf` as `omega -> 0`. No limit
  `omega -> 0` of the Hamiltonians is taken.
- The introduction states the general difficulty: "the reason why an entire function E satisfying (1.1) ...
  belongs to HB is not known other than RH and SC [simplicity], so we do not know how to prove E in HB without
  RH and SC"; and of the inverse problem: known constructions "are usually not applicable if it is not known
  whether E in HB-bar".

## 6. What it explicitly does not do (checked over the whole text)
- It does not use the Weil quadratic form, test functions of compact support, or any window form. The operators
  `K[t]` are of Hankel type (kernel `K(x+y)`) on a half-line, built from the ratio `xi(s-omega)/xi(s+omega)`; the
  words "Weil explicit formula" occur only in Remark (2) and in the motivation.
- No derivative or monotonicity statement in `t` or `omega` for `gamma(t)` or the determinants; no computed
  value of `tau`; no numerical example (Remark (4) only says how one could compute).
- No statement on what happens to `gamma(t)` at the points `t = (1/2) log n` where new coefficients enter;
  `K` is continuous there by construction (that is what condition (2.8) is for).
- No example outside the Selberg class and no control case; the statement that the Euler product "is
  essential" (Remark (2)) is about the construction of `K`, and is not accompanied by a counterexample.
- The local Hamiltonians `H_{L,p}` of the Euler factors (from Suzuki's 2018 paper on self-reciprocal
  polynomials) are mentioned, not used.

- **rh/THEORY.md T16** ("(Statement as recorded, not exact.) GRH ... is equivalent to the existence, for every
  value a > 0 of a parameter, of the Hamiltonian of a canonical system"): the exact statement is Theorem 2.4
  above. Differences from the recorded wording: (a) the parameter over which the condition is imposed is a
  sequence of shifts `omega_n -> 0` together with powers `nu_n` (`nu_n omega_n d_L > 1`), not a window size and
  not "every a > 0"; (b) existence of the Hamiltonian on the whole half-line (condition (3)) is only one of two
  conditions; the limit condition (4) `J(t;z,z) -> 0` is also required, and the paper does not show it follows
  from (3); (c) the class is `S_R`, not the whole Selberg class.

  is in this paper is a canonical system in a cut-off variable `t` for which, as in A4, only finitely many

## 8. Open questions the paper itself states
- Remark (2): "to extend the construction of H and [the solution] to the class of L-data" of Booker (an
  axiomatic framework without an explicit Euler product, based on the explicit formula).
- Remark (3): "to find a relation among the perturbation family of global Hamiltonians H_L^{omega,nu}, the family
  of local Hamiltonians H_{L,p} and the conjectural Hamiltonian H_L corresponding to E(z) = xi_L(s) + xi_L'(s)".
- Remark (5): the role of the behaviour of `K(x)` as `x -> +inf`.
- Remark (6): whether the stronger condition (4') (convergence of `(A(t,z), B(t,z))` to `(E(0), 0)`) is also
  necessary; whether `lim_{t -> inf} A(t,z)` exists.
- Introduction and section 7: the Hamiltonian for `omega = 0` (for `xi + xi'`) and the "genuine Polya-Hilbert
  space" as a limit of the family; no statement of how such a limit would be taken.
