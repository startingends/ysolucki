## 2. Main statements, with their numbers
Setting: `Q(m,n) = am^2 + bmn + cn^2`, a,b,c integers, fundamental discriminant D < 0, h(D) > 1.
`E(s,Q) = (w/h) sum_chi conj chi(a_Q) L(s,chi) = sum_{j=1}^J a_j L(s,chi_j)` (class-group characters, conjugates
merged; J = 1 iff h = 1).
- **Theorem 1.1 (Voronin 1976, quoted).** h(D) > 1: for 1/2 < sigma_1 < sigma_2 < 1, at least cT zeros in
  sigma_1 < Re s < sigma_2, |Im s| < T, c = c(sigma_1, sigma_2, Q) > 0.
- **Davenport-Heilbronn (quoted, sec. 1):** h(D) > 1 => E(s,Q) has infinitely many zeros in Re s > 1.
- **Theorem 1.2 (Bombieri-Mueller 2008, quoted)** for Q_1 = m^2 + 5n^2, Q_2 = 2m^2 + 2mn + 3n^2: for
  1 < sigma_1 < sigma_2 < sigma(Q_i) (sigma(Q) = sup of real parts of zeros) the count has exact order T.
- **Bombieri-Hejhal (quoted):** under GRH for the L_j and a weak zero-spacing hypothesis, almost all zeros of
  `sum b_j e^{i alpha_j} L_j(s)` (common functional equation) are simple and on the line. Hejhal (CRAS 2004,
  announced): outside a small set of coefficients, the number of zeros with Re s >= sigma, T <= Im s <= T+H is of
  order `H/((sigma - 1/2) sqrt(log log T))` for 1/2 + (log log T)^kappa/log T <= sigma <= 1/2 + (log T)^{-delta}.
- **Theorem 1.3 (main, unconditional).** Same hypothesis as Thm 1.1. For any 1/2 < sigma_1 < sigma_2, E(s,Q) has
  `cT + o(T)` zeros in sigma_1 < Re s < sigma_2, |Im s| < T, c = c(sigma_1, sigma_2, Q) >= 0; c > 0 if
  sigma_1 <= 1; for Q_1, Q_2, c > 0 whenever 1/2 < sigma_1 < sigma(Q_i). The density is
  `c = int_{sigma_1}^{sigma_2} G_sigma(0) d sigma` (eq. (3.?) "eqn:5"; for J = 2, `G_sigma(-a)` with a = a_1/a_2,
  positive for 1/2 < sigma <= 1, eq. "eqn:4").
- **Theorem 1.4.** For fixed sigma_0 > 1/2, the zeros with Re rho = sigma_0 exactly, 0 < Im rho < T, are o(T).
- **Theorem 4.1** (almost periodicity, Davenport collected works, Montgomery's comment): one zero in Re s > 1
  forces >= c_delta T zeros in any strip of width 2 delta around it. **Corollary 4.2:** c(1, sigma, Q) > 0 for all
  sigma > 1, c(sigma, sigma(Q), Q) > 0 for 1/2 < sigma < sigma(Q); c(sigma_1, sigma_2, Q) = 0 with
  1 < sigma_1 < sigma_2 < sigma(Q) forces no zeros at all in that strip. **Corollary 4.3:** only finitely many
  zero-free vertical strips (Jessen-Tornehave mean motion, Theorem 4.4 = JT Thm 31).

## 3. The method in ten lines
Borchsenius-Jessen mean-motion theory: the Jensen function `phi_f(sigma) = lim (1/T) int log|f(sigma+it)| dt` is
convex and `(1/2pi)(phi'(sigma_2) - phi'(sigma_1))` is the zero density in the strip (Thm 3.1 = BJ Thm 1). The work
is to show `phi''_E(sigma) = 2 pi G_sigma(0)` for sigma > 1/2 (not only in the half-plane of almost periodicity):
truncated Euler products `L_n` converge in mean (index 2) on [1/2, inf] (Prop. 2.2, approximate functional
equation); the distribution of `E_n(sigma + it)` weighted by `|E_n'|^2` is computed on the torus [0,1]^n by
Kronecker-Weyl (Lemma 2.6) and has a smooth density with Fourier decay `|y|^{-J}` (stationary phase, Lemma 2.4,
plus equidistribution of split primes in ideal classes, Lemma 2.5). For J = 2 this is a direct application of
Borchsenius-Jessen to `L(s,chi_2)/L(s,chi_1) + a`.

## 4. What is assumed
Nothing beyond the theorems quoted; Theorem 1.3 is unconditional. Positivity of c inside the strip for J >= 3
comes from Voronin's theorem, not from the method.

## 5. Where its frontier is
Proved: asymptotic density cT of off-line zeros in every strip to the right of 1/2 (rational forms, h > 1).
Not proved: positivity of c for 1 < sigma_1 < sigma_2 < sigma(Q) for general Q ("We expect, but are not able to
prove"); the density near sigma = 1/2 at scale 1/log T (only Hejhal's announcement). Integer coefficients are
essential (class-group characters); NOTHING is said about forms with irrational coefficients (generic z).

## 6. What it explicitly does not do
No statement for h(D) = 1 (where E(s,Q) = (w) zeta_K(s) and RH is expected); no family in Q; no zeros on the line.

## 7. Facts in our own record that this paper corrects or shows to be already known
- **rh/NOTEBOOK.md N45 (3)** "class number > 1 at CM points has zeros off the line (Davenport-Heilbronn;
  Bombieri-Hejhal; recalled)": KNOWN, and stronger than recalled: unconditionally a positive density cT + o(T) of
  zeros in EVERY strip 1/2 < sigma_1 < sigma_2 <= 1 (Voronin; Lee Thm 1.3), and infinitely many in Re s > 1
  (Davenport-Heilbronn). Bombieri-Hejhal is the opposite statement (almost all zeros ON the line, conditional on
  GRH + spacing); it is not a source of off-line zeros.
- **OBJECT_PHI section 4 (iii)** "for CM points of class number > 1, Dfc > 0 (KNOWN from memory)": KNOWN; more:
  (reader's remark, elementary) for rho = beta + i gamma, log|rho/(1-rho)| = (2 beta - 1)/(2 gamma^2) + O(gamma^-3),
  so Dfc(z_D) is a convergent sum over >= cT off-line zeros up to height T, each term positive.
- "Generic z": this paper (and every paper read here) covers integral forms only; whether E(z, .) has off-line
  zeros for z with transcendental j(z) is NOT settled by anything read in this session (see report).
