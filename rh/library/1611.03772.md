## 2. Main theorems (exact statements, numbers as in the paper)
Objects: for a sequence α on ℕ, the **Helson matrix** M(α) = {α(nm)}, n, m ≥ 1 ("multiplicative Hankel
matrix"), as a form/operator on ℓ²(ℕ). With n = p^κ (prime factorisation as a multi-index), M(α) is a Hankel
matrix in countably many variables; H²(𝕋^∞) is the Hardy space of the infinite polytorus, with reproducing
kernel K_∞(z,w) = Π_j (1 − z_j w̄_j)^{−1} on 𝔻^∞ ∩ ℓ². The Bohr lift sends Σ f_n n^{−s} to Σ f_n z^{κ(n)}.

- **Thm 2.1 (Nehari; Ferguson–Lacey; Lacey–Terwilleger), Thm 2.2 (Ortega-Cerdà–Seip), recalled.** In d < ∞
  variables bounded Hankel = bounded symbol, with constant C_d ≥ (π²/8)^{d/4}; hence "There exists a bounded
  Helson matrix M(α) such that there is no A ∈ L^∞(𝕋^∞)" representing it. "no explicit examples … are available."
- **Thm 3.1 (Hamburger, Stieltjes), Thm 3.2 (d variables, under |β(κ)| ≤ C^{|κ|} Π κ_j^{κ_j}), recalled.** In
  d > 1 variables there are non-negative Hankel matrices that are not moment sequences (Berg–Christensen–
  Ressel §6.3); a growth condition repairs this.
- **Thm 3.3 (cited to Berezanskiĭ 1968, Berg–Christensen–Ressel 1984, Samoĭlenko 1991; "a combination of
  results existing in the literature"; only a sketch of proof is given).** "Let α = {α(n)} be a sequence of
  complex numbers which satisfies the bound α(n) = O(n^a), n → ∞, for some finite a > 0. Then
  (i) M(α) ≥ 0 if and only if there exists a measure μ ≥ 0 on ℝ^∞ such that t^κ ∈ L¹(μ) for all multi-indices
  κ and α(n) = ∫_{ℝ^∞} t^κ dμ(t), n = p^κ. In this case the measure μ is unique.
  (ii) We have M(α) ≥ 0 and M(α(p·)) ≥ 0 for all primes p if and only if there exists a measure μ ≥ 0 as above,
  supported on [0,∞)^∞."
  Remark after it: (ii) implies M(α(ℓ·)) ≥ 0 for every integer ℓ; "This should be a purely algebraic fact,
  but we do not know how to prove this directly".
- **Thm 4.2 (Widom 1966), recalled; Thm 4.3 (new, d < ∞).** For μ ≥ 0 finite on (−1,1)^d with moments β:
  H_d(β) bounded ⇔ μ Carleson for H²(𝕋^d) ⇔ μ(I_s) ≤ C Π(1 − s_j) (box condition) ⇔ the integral operator
  G_d with kernel K_d on L²(μ) is bounded ⇔ |β(κ)| ≤ C Π 1/(1+κ_j). H_d(β) and G_d are unitarily equivalent
  modulo kernels (Remark 4.4).
- **Thm 4.5.** A Carleson measure for H²(𝕋^∞) on 𝔻^∞ has a bounded Helson matrix of moments.
- **Thm 4.7.** "Let μ ≥ 0 be a finite measure on (−1,1)^∞, and let α(p^κ) = ∫ t^κ dμ(t). Then the following
  are equivalent: (1) M(α) defines a bounded operator on ℓ²(ℕ). (2) μ is a Carleson measure for H²(𝕋^∞).
  (3) The operators G_d : L²(μ) → L²(μ) are bounded and converge in the strong operator topology to a limit
  G_∞." A bounded non-negative M(α) has α(n) → 0 and its measure sits on (−1,1)^∞.
  Remark 4.10: "there is no simple coefficient condition to characterize boundedness": 1/(√n log n) gives a
  bounded matrix, anything with α'(n)√n log n → ∞ an unbounded one, yet α(2^k) = 1/(1+k), 0 elsewhere, is bounded.
- **Thm 5.1 (measures on the half-line, through the Bohr map s ↦ (p^{−s})_p).** "Let ν be a finite positive
  measure on (1/2,∞), and let α(n) = ∫_{1/2}^∞ n^{−s} dν(s), n ≥ 1. Then the following are equivalent:
  (1) M(α) is a bounded operator on ℓ²(ℕ). (2) There is C > 0 such that ν((1/2, s]) ≤ C(s − 1/2), s → 1/2.
  (3) There is C > 0 such that α(n) ≤ C/(√n log n), n ≥ 2. (4) The Hankel type integral operator
  (Gf)(t) = ∫_{1/2}^∞ ζ(s+t) f(s) dν(s) is bounded on L²(ν)." M(α) and G are unitarily equivalent modulo
  kernels. (The paper notes ν must live on (1/2,∞) if α ∈ ℓ².)
- **Thm 5.2 (from Brevig–Perfekt–Seip–Siskakis–Vukotić and the authors' companion paper).** "The
  multiplicative Hilbert matrix H [= {1/(√(nm) log(nm))}, n, m ≥ 2] is bounded on ℓ²(ℕ_2). Its spectrum is
  purely absolutely continuous (no eigenvalues, no singular continuous component), has multiplicity one and
  coincides with [0, π]." It is the case dν = ds "with a minor modification … to eliminate n = 1".
- **Thm 6.6 (the paper's main new theorem; Kronecker's theorem for Helson forms).** "(i) The form [·,·] has
  finite rank if and only if it can be represented as a finite sum [f,g] = Σ_ℓ D(c^{(ℓ)})(fg)(λ^{(ℓ)}), where
  for each ℓ, D(c^{(ℓ)}) is a factorizable differential operator of a finite order and λ^{(ℓ)} ∈ ℂ^∞.
  (ii) The form is bounded … and of finite rank if and only if the representation can be chosen such that
  for all ℓ, one has λ^{(ℓ)} ∈ 𝔻^∞ ∩ ℓ² and c^{(ℓ)} ∈ ℓ²." Bounded finite-rank Helson matrices have bounded symbols.
  Example 6.4: [f,g] = D^n(fg)(ρ) (n-th derivative in s of the Dirichlet polynomial at ρ) has rank n+1 and
  "is bounded if and only if ρ ∈ ℂ_{1/2}".
- **Cor. 6.8.** "A finite rank Helson form is non-negative if and only if there exist finitely many points
  λ^{(ℓ)} ∈ ℝ^∞ and finitely many positive numbers c^{(ℓ)} > 0 such that [f,g] = Σ_ℓ c^{(ℓ)} f(λ^{(ℓ)}) g(λ^{(ℓ)})."
- **Prop. A.2, A.3 (appendix).** A Carleson measure on (−1,1)^∞ satisfies μ(I_s) ≤ C Π(1 − s_j²); but there
  is a positive measure on (−1,1)^∞ passing the reproducing-kernel test that is not Carleson (product
  measures with ‖M(α_N)‖ = (π/2)^N and test norm 1).

## 3. The method in ten lines
1. n = p^κ turns α(nm) into β(κ+κ'): a Hankel form on the additive semigroup ℕ_0^{(∞)}.
2. Non-negativity: GNS-type Hilbert space from the form; multiplication by each variable t_j is a symmetric
   operator; the polynomial growth of α makes each one-variable moment problem determinate, so (Devinatz)
   each operator is essentially self-adjoint; the joint spectral theorem for countably many commuting
   self-adjoint operators (Samoĭlenko) gives μ; Kolmogorov extension gives uniqueness.
3. Boundedness of non-negative matrices: M(α) = 𝒩*𝒩 with 𝒩 the embedding H²(𝕋^∞) → L²(μ); so bounded ⇔
   Carleson, and 𝒩𝒩* is an integral operator on L²(μ) (Widom's argument, extended).
4. Half-line case: the same factorisation with 𝒩{a_n} = Σ a_n n^{−t}; 𝒩𝒩* has kernel ζ(s+t); the pole of ζ at 1
   gives the linear growth condition on ν at 1/2.
5. Finite rank, algebra: the kernel of a Helson form is an ideal of finite codimension in ℂ[z_1, z_2, …];
   reduce to finitely many variables by a ring homomorphism (Lemma 7.2), apply Power's theorem, push back
   with the chain rule; directions of differentiation may have infinitely many non-zero coordinates.
6. Finite rank, analysis: point evaluation is bounded on H²(𝕋^∞) iff the point is in 𝔻^∞ ∩ ℓ²; separate
   points and orders with multiplier polynomials; a symmetric-tensor lemma puts the directions in ℓ².
7. Counterexample in the appendix: closed graph theorem against tensor powers of a Hilbert-type matrix.

## 4. What is assumed
- Thm 3.3: α(n) = O(n^a). The authors: this "is only a simple sufficient condition" for determinacy of all
  finite-variable sections. Without a growth condition the moment representation can fail (in d > 1 variables).
- Indices run over n, m ≥ 1 throughout (α(1) is the total mass of μ). Boundedness results assume M(α) ≥ 0.
- Measures on ℝ^∞ with the product σ-algebra.

## 5. Where its frontier is
- **Last things it proves:** the complete description of finite-rank Helson matrices (Thm 6.6), and
  "bounded non-negative ⇔ Carleson measure" (Thm 4.7).
- **First things it cannot (the paper's own words):** Carleson measures for H²(𝕋^∞) "are notoriously
  difficult to understand, and we leave the topic with many remaining question marks"; the box/kernel test is
  shown insufficient (Prop. A.3) and no usable test replaces it; Question 4.6 is open, and "when d > 1 we do
  not know if such a result holds even in the finite variable Hankel setting"; "we do not know how to
  explicitly diagonalize H".
- The description of ALL bounded Helson matrices (question (a) of the introduction) is not obtained: only the
  non-negative ones, and those only up to the Carleson condition.

## 6. What it explicitly does not do
- No zeros of ζ, no explicit formula, no von Mangoldt function, no Euler products. ζ enters only as the
  kernel ζ(s+t) of Thm 5.1 and through its pole at s = 1.
- No characterisation of non-negativity for matrices indexed from n, m ≥ 2. The only matrix on ℕ_2 in the
  paper is the multiplicative Hilbert matrix, treated for boundedness and spectrum, not as a moment problem.
- No closed rank formula ("a difficult combinatorial problem already when d = 2").
- No statement relating non-negativity of a Helson matrix to any other positivity (Toeplitz/shift type).

  is represented as the moment sequence of μ?" (unknown even for Hankel matrices in d > 1 variables).
- A direct algebraic proof that M(α) ≥ 0 and M(α(p·)) ≥ 0 for all primes p imply M(α(ℓ·)) ≥ 0 for all ℓ.
- An explicit bounded Helson matrix without bounded symbol.
- Whether a measure that is Carleson for H²(𝕋^∞) but not for H¹(𝕋^∞) can be concentrated on (−1,1)^∞ (Remark 4.11).
- An explicit diagonalisation of the multiplicative Hilbert matrix.
