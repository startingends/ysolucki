## 2. Statements in the part read
- Abstract (main result of the paper, not read in the body): there is a unique a_0 in (0,1/2) with Q(sigma,a_0)
  having a double real zero at sigma = 1/2; no zero in (0,1) for a in (a_0, 1/2]; at least two real zeros in (0,1)
  for a in (0, a_0). (A one-parameter family whose real zeros are born by a collision at s = 1/2, like the
  constant term at y* in Lagarias-Suzuki.)
- **Theorem B (Bateman-Grosswald 1964, announced by Chowla-Selberg 1949), as quoted:** for a positive definite
  REAL binary form B = ax^2 + bxy + cy^2, `kappa^2 = (4ac - b^2)/(4a^2)` (= y^2 for the reduced point z = x+iy), with
  kappa >= sqrt3/2: `zeta_B(1/2) > 0` if kappa >= 7.00556 ("or if 4 kappa^2 >= 199.2"), `zeta_B(1/2) < 0` if
  sqrt3/2 <= kappa <= 7.00554 ("or if 3 <= 4 kappa^2 <= 199.1"); no result for kappa in between. Consequence stated:
  zeta_B vanishes in (1/2, 1) if kappa >= 7.00556 (intermediate value theorem, zeta_B(sigma) -> -inf as sigma -> 1-);
  "it is probable that zeta_B(sigma) < 0 for all sigma in (0,1)" below.
  (Reader's note: the printed numbers are mutually inconsistent: sqrt(199.2)/2 = 7.057, and Lagarias-Suzuki quote
  the same theorem as 7.0556 / 7.0554; the constant-term threshold is exactly 4 pi e^{-gamma} = 7.05551 and, by this
  reader's computation in `2110.09368.md`, the zero of E*(iy, 1/2) is at y = 7.05551 (1 - 4.2e-20). The "7.0055x"
  in this source is presumably a misprint of 7.055x.)
- Riemann-von Mangoldt for Epstein (Steuding 2006, p. 692): `N(T) = (2T/pi) log(|d|^{1/2} T/(2 pi e m(B))) + O(log T)`.
- Potter-Titchmarsh: >> T^{1/2-eps} zeros on the line; best known (2022) >> T^{4/7-eps} (Baier-Srinivas-Sangale) for
  general (real) forms; Davenport-Heilbronn, Voronin, Lee, Lamzouri for integral forms with h >= 2.

## 7. Facts in our own record that this paper corrects or shows to be already known
- **OBJECT_PHI sec. 4 / N45** (RH set): for EVERY z (real form, any x) with Im of the reduced point >= about 7.056,
  E(z, .) has a real zero in (1/2, 1) (Bateman-Grosswald as quoted here and in Lagarias-Suzuki): the RH set is
  contained in {Im z_red < 7.056}, and Dfc > 0 on the whole cusp neighbourhood beyond that height.
- For generic real z, the only unconditional zero facts found: zeros on the line >> T^{4/7 - eps}, and the real
  zero for large y. No theorem on complex off-line zeros for non-integral forms was found in this session.
