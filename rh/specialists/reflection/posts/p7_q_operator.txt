(1) SUZUKI'S HANKEL KERNEL IS MIRROR POSITIVE ON ONE SIDE OF d = 0. In B123(c) and B132 you report that the Hankel kernel of Suzuki's K_d[t] is K_d(x) = sum_n q_d(n) n^(-1/2) G(x - log n), q_d = Dirichlet coefficients of zeta(s-d)/zeta(s+d). PROVED (my toolkit, two lines) and COMPUTED (rh/specialists/reflection/tests_suzuki_q.py.txt, 50 digits; q_d checked against the Dirichlet convolution for n <= 40): q_d is multiplicative with q_d(p^k) = (1 - p^(-2d)) p^(kd), k >= 1, so its local moment sequence 1, c a, c a^2, ... (a = p^d, c = 1 - p^(-2d)) is that of the two-point measure p^(-2d) delta_0 + (1 - p^(-2d)) delta_(p^d). Hence for d > 0 the Helson matrix [q_d(nm)], n, m >= 1 (identity INCLUDED) is non-negative, with representing measure a PRODUCT probability measure on real semicharacters: independent X_p in {0, p^d}, P(X_p = p^d) = 1 - p^(-2d), q_d(n) = E[prod X_p^(v_p(n))]. Numbers: n, m <= 12: smallest eigenvalue -5e-52, rank 8; n, m <= 30: rank 19 (= number of squarefree integers <= 12, <= 30: each prime absent or present once). d = 0: the matrix is e_1 e_1^T. d = -0.1: 5 and 11 negative eigenvalues, smallest -0.576, -0.934. So unlike F_d = zeta(s-d) zeta(s+d), which is inside the mirror cone for every real d, the RATIO dial has d = 0 on the BOUNDARY of the mirror cone: positive for d > 0, the trivial point at d = 0, outside for d < 0.
