Q3 OF THE LEAD: WHAT SINGLES OUT THE SPECIAL POINTS OF THE THETA DIAL, AND WHETHER 'HAS AN EULER PRODUCT' IS A POSITIVITY (proofs: rh/specialists/modular/PROOF_dial.md; NOTES_session1.md D9-D11). r_n(m) = coefficient of q^m in theta^n = (1 + 2q + 2q^4 + ...)^n, n real.
(1) PROVED, a finite identity (hand computation; then exact rational arithmetic at 16 values of n, both sides of degree <= 7; prediction first, hit):
        2n r_n(6) - r_n(2) r_n(3) = (8/45) n^3 (n-1)(n-2)(n-4)(n-8).
So a(m) = r_n(m)/r_n(1) satisfies a(2)a(3) = a(6) iff n in {1, 2, 4, 8}: Z_n(s) = sum r_n(m) m^-s can be an Euler product ONLY at n = 1, 2, 4, 8, the dimensions of the real normed division algebras (where Z^n carries an order whose norm form is the sum of n squares). Conversely it is one there (Jacobi's formulas, from memory; COMPUTED: the defect vanishes at 1, 2, 4, 8 for seven more coprime pairs, and equals -0.936, -2.009, -2.263 at n = 1.2, 1.4, 1.8, 48 at n = 3, -3072 at n = 6).
(2) THREE LEVELS, not one. (i) Non-integer n: no Hecke operators at all. Reason FROM MEMORY, unread (Wohlfahrt 1957; Kubota-Moore-Matsumoto): the automorphy factor of real weight lives on a cover of SL2(R) of degree > 2, and Hecke operators need the cover to split over the commensurator SL2(Q); over Q only the double cover does. Read this session, in support: Berger's theorem (Long's survey): on a non-congruence subgroup T_p factors through the trace to the congruence closure. (ii) Odd n: only T(p^2). KNOWN, read (arXiv 2011.07796): Theta^3, Theta^5, Theta^7 are eigenforms of T(p^2), eigenvalues 1+p, 1+p^3, 1+p^5: an Euler product in the square direction only. (iii) Full Euler product: n in {1, 2, 4, 8} by (1); n = 6 is a difference of two Euler products (from memory).
(3) A POSITIVITY THAT DOES SINGLE OUT POINTS, BELOW n = 4. PROVED: r_n(2) = 2n(n-1) < 0 on (0,1); r_n(3) = (4/3)n(n-1)(n-2) < 0 on (1,2); r_n(7) = n(n-1)(n-2)(n-3)[8/3 + (8/315)(n-4)(n-5)(n-6)] < 0 on (2,3). With Bondarenko-Radchenko-Seip Prop. 3.1 (read: dim M_k(Gamma_theta,+) = 1 + floor(k/4), real k): for 0 < n <= 3, a non-zero f = sum_{m>=0} a_m e^(pi i m tau) with a_m >= 0 of polynomial growth and f(-1/tau) = (tau/i)^(n/2) f(tau) EXISTS IFF n in {1, 2, 3}. In words: a Poisson summation formula 'in dimension n' carried by a positive measure on the radii sqrt(m) exists, for n <= 3, exactly where there is a lattice to count. COMPUTED (exact rationals; prediction 'none at n = 3.5' MISSED): negative coefficients at n = 3.1 (m = 28, 47), 3.5 (m = 16, 40, 64), 3.9 (m = 64, 128, 256); none among the first 1000 for n = 4.5, 5.5, 6.5, 7.5. So this positivity sees the integers only below 4, and it does not see the Euler product (n = 3 passes).
(4) IS 'HAS AN EULER PRODUCT' A POSITIVITY? NO; it is the extreme point of one. PROVED (3 lines): for commuting self-adjoint Hecke operators the Gram matrix [<T_m f, T_n f>] is positive semidefinite for EVERY f, and has rank one iff f is an eigenform (equality in Cauchy-Schwarz). In coefficients, level 1: [sum_{d|(m,n)} a(mn/d^2)] is >= 0 iff a is a non-negative mixture of eigen-systems, rank one iff a single one. For degree one this matrix is SP-reflection's Helson matrix [a(mn)] and the statement is B137's 'extreme rays = single semicharacters'. And the defect in (1) changes sign at every special point (< 0 on (1,2) and (4,8), > 0 on (2,4)): no one-sided inequality in n cuts out the Euler products.
(5) CORRECTION to the roster's pairing sentence 'mirror positivity holds exactly where Hecke operators exist'. As a general statement it is FALSE: mirror positivity at p <=> local roots real with positive multiplicities (B117); a Hecke eigen CUSP form of weight >= 2 has complex conjugate roots (Deligne), hence is mirror NEGATIVE (L(Delta): -3.62 on the board). True: among Hecke eigenforms, mirror positive <=> Eisenstein type with real characters and no numerator factor; with Ramanujan this leaves roots +-1 only (S1-mirror B90). On the dial it holds at n = 1, 2 only (n = 4, 8 have a numerator at 2: the one negative square of B2).
(6) BLIND TO B11: F_d and G_d pass (1), (3), (4). And a caution for N38: coefficients that COUNT are not enough (Epstein zeta functions of class number > 1 count lattice points, have a functional equation and zeros off the line; n = 3 counts and has no Euler product). N38's count has to be attached to window functions, not to coefficients.
