## 0. Two book-keeping facts that change what "trivial" means (PROVED)
(0.1) Copies multiply. Rows u = w^6 with N(w) <= H^(1/6) number about c H^(1/6), and on them psi_u is the principal character
     restricted to (n, w) = 1. Hence for the coefficient vector c_n = W(N(n)/D) (no mu), S >= c H^(1/6) D^2. So NO inequality valid
     for all bounded coefficient vectors gives S(H, D) << D^2 over ALL rows: the general norm over all rows is >= H^(1/6) D^2.
     The bound S << D^(2+eps) quoted in SHORT_FAMILY 2(d) is the squarefree-row bound (Delta(D^(1/2), D) = D). Over all rows,
     S(D^(1/2), D) << D^(2 - delta) for the Moebius vector would give, by the paper's (3.2) with Y = H^(1/6) = D^(1/12),
     |A_1| << D^(1 - delta/2 - 1/24 + eps): zero-free Re s > 23/24 - delta/2. So "any power saving over D^2" is already a zero-free
     half-plane at delta = 0; the question B10 (d) asks is (correctly) whether the Vaughan mechanism produces anything at the copies.
(0.2) L^1 versus L^2. Bombieri-Vinogradov is an L^1 statement over the family; S is L^2. The two amplify differently (PROVED, same
     argument as (3.2) of the 11/12 paper): sum_u |A_u| <= B_1 gives |A_1| << B_1 log Y / Y, while S <= B_2 gives |A_1| << (B_2 log Y / Y)^(1/2).
     The "one member" levels are B_1 = D and B_2 = D^2; with copies Y ~ H^(1/6) they would give Re s > 1 - eta/6 (L^1) and 1 - eta/12 (L^2).
     At eta = 1/2 the L^1 one-member level D coincides with the L^1 diagonal H D^(1/2) and would give 11/12 (the paper's number, by a
     different route). Neither level is reachable by the mechanism below once copies are counted.

## 1. The identity (KNOWN, read; PROVED in the general form)
(1a) KNOWN, read (Dunn 2403.13151, Prop. "vaughanid", over Z[omega], nu = 1 mod 3, N(nu) > S): Lambda(nu) = sum_{a|nu, N(a)<=R} mu(a)
     log(N(nu)/N(a)) - sum_{ab|nu, N(a)<=R, N(b)<=S} mu(a)Lambda(b) + sum_{ab|nu, N(a)>R, N(b)>S} mu(a)Lambda(b). Dunn applies it to cusp-form
     coefficients twisted by Lambda over Z[omega] with RS > 10^4 X so that the Type II term is EMPTY, and treats the middle term twice
     (as averaged Type I and as Type II). The same algebra gives the Moebius form.
(1b) PROVED (formal algebra, any Dirichlet series F = sum a_n n^-s with a_1 = 1, G = 1/F = sum c_n n^-s, G_U = sum_{n<=U} c_n n^-s):
        1/F = 2 G_U - F G_U^2 + (1/F)(1 - F G_U)^2,     and (1 - F G_U) has coefficients h_n = 0 for n <= U.
     Expanding (1/F)(1 - 2 F G_U + F^2 G_U^2) = 1/F - 2G_U + F G_U^2 proves it; F G_U agrees with F G = 1 on n <= U because every divisor
     of such n is <= U. For F = L_K(s, nu psi) (completely multiplicative coefficients) this is Vaughan's identity for mu nu psi:
        mu = 2 mu_{<=U} - 1 * mu_{<=U} * mu_{<=U} + mu * g * g,    g(m) = -sum_{d|m, N(d)<=U} mu(d) for N(m) > U, g = 0 otherwise,
     and since psi_u is completely multiplicative in n, the twist passes through every convolution. For n ~ D (U < D): A_u = I_u + II_u,
        I_u = - sum_{N(d)<=U^2} (mu_U * mu_U)(d) nu psi_u(d) sum_m nu psi_u(m) W(N(dm)/D)          (Type I, smooth variable m),
        II_u = sum_{N(m)>U} g(m) nu psi_u(m) sum_k (mu*g)(k) nu psi_u(k) W(N(mk)/D),  (mu*g)(k) = 0 for N(k) <= U   (Type II, M, N in [U, D/U]).
     THE IMPOSTOR HAS THE IDENTITY (1b) VERBATIM (it is algebra for any invertible series). What it lacks is listed in section 5.

## 2. Type I in the sparse family (PROVED; no Burgess needed)
(2a) Smoothed Polya-Vinogradov over O. For psi primitive of conductor q, Poisson over the lattice O (the 11/12 paper's Lemma 4.2 is
     this computation) gives sum_m psi(m) W(N(m)/Y) = (Y/N(q)) tau(psi) sum_{h != 0} conj psi(h) What(h, Y/N(q)), with What decaying
     faster than any power once N(h) >> D^eps N(q)/Y. Since psi is non-principal the h = 0 term is absent. Hence the sum is
     O_A(D^(-A)) if Y >= N(q) D^eps, and << N(q)^(1/2+eps) otherwise. Imprimitive psi_u: Moebius-invert the condition (m, u) = 1 (at most
     D^eps terms, lengths divided by divisors of u of norm <= H).
(2b) In I_u the smooth length is Y = D/N(d) >= D/U^2 and N(cond psi_u) <= N(u) <= H. So if U^2 <= D^(1-eps)/H, every NON-COPY row has
     I_u = O(D^(-A)). At H = D^(1/2): U <= D^(1/4 - eps). Burgess-type bounds (character sums shorter than the conductor) would be needed
     only for U^2 > D/H; Polya-Vinogradov/Poisson is enough. On COPY rows psi_u is principal and I_u is a main term,
     ~ D Res zeta_K hat W(1) (sum_{N(a)<=U} mu(a) nu(a)/N(a))^2 times local factors: of size D M_U(1)^2, a PNT-strength quantity, which
     the Type II part on the same row must cancel; on copy rows the untwisted Type II form is the original problem (A_u = A_1 + O(D/N(p))).
(2c) Heath-Brown's identity with k factors (FROM MEMORY: Iwaniec-Kowalski 13.37-13.38) does the same with the rough variables <= D^(1/k):
     every piece with a smooth variable of length >= H D^eps is negligible on non-copy rows; the rest regroups (all variables < H D^eps =
     D^(1/2+eps)) into bilinear forms with M in [D^(1/4), D^(1/2)] (if every variable is <= D^beta, some subproduct lies in
     [D^((1-beta)/2), D^((1+beta)/2)]: elementary greedy argument). So Type I level D^(1/2) (relative to conductor H) forces Type II
     on M in [D^(1/4), D^(1/2)], N = D/M. That is the exact Type II range required.

## 3. Type II: what the bilinear large sieve gives in the sparse family
(3a) L^2, i.e. the quantity S. PROVED LOWER BOUND, every (M, N), every H >= 1: let u_0 be any row and alpha_m = conj nu psi_{u_0}(m) 1_{N(m)~M},
     beta_k = conj nu psi_{u_0}(k) 1_{N(k)~N} (bounded by 1). Then row u_0 of the bilinear form equals sum_{m,k} W(N(mk)/D) >> MN = D
     (positivity of W), so sum_u |II_u|^2 >= c D^2. Hence NO bilinear inequality valid for bounded coefficients beats D^2 in any range;
     over all rows (copies) the same vectors with u_0 = 1 give >= c H^(1/6) D^2. Upper bounds match: min{Delta(H,D) D, M^2 Delta(H,N) N,
     N^2 Delta(H,M) M} has exponent exactly 2 for H <= D^(1/2) (COMPUTED in typeII_exponents.log for the proved, the dFDH-conjectured,
     an idealised quadratic-type and the full-family sieves, eta = 1/4, 1/2: all 2.0000). ANSWER, L^2: the range of (M, N) in which the
     bilinear large sieve beats D^2 is EMPTY. It beats the family-trivial H D^2 by the factor H everywhere, which is just the large sieve.
(3b) L^1 (the Bombieri-Vinogradov normalisation), non-copy squarefree rows, Type II only:
        sum_{N(u) ~ H} |II_u| <= (sum_u |A_u(M)|^2)^(1/2) (sum_u |B_u(N)|^2)^(1/2) << D^(1/2) (Delta(H,M) Delta(H,N))^(1/2).
     PROVED exponent bookkeeping (COMPUTED as a check, typeII_exponents.log): at H = D^(1/2), M = D^a, a in [1/4, 1/2]:
     Delta(H,M) = D^((1+2a)/3), Delta(H,N) = D^((3-2a)/3), total D^(7/6) for EVERY a in the range (the 2/3-term dominates both factors);
     per-row average D^(2/3): a power saving D^(1/3) per row ON AVERAGE, against the per-row trivial D. With dFDH's conjectured sextic
     norm: total D^(55/48); with an idealised (A + B) norm: D^(9/8), reaching D only at the single point M = N = D^(1/2).
     For H <= D^(1/5) the total is D^(1+eps): "the whole primitive family weighs no more than one member" (threshold eta = 1/5 from
     (1-eta)/2 >= (1+eta)/3).
     So in L^1 the range in which the bilinear large sieve beats the trivial bound is the WHOLE required range [D^(1/4), D^(1/2)], with
     saving D^(1/3) per row; in no part of it does it reach the one-member line D, and it never touches the copy rows.
(3c) What this is (KNOWN in type, FROM MEMORY: Montgomery's large-values method, Huxley's large sieve over number fields, zero-density
     estimates for families of Hecke characters): (3b) is a ZERO-DENSITY statement for the family {L_K(s, nu psi_u)}. A zero of row u
     at beta forces |A_u(D)| >= D^(beta - eps) along a sequence of D (Mellin, as in step 1 of the 11/12 paper), so (3b) gives
     #{primitive rows of norm ~ H with a zero in Re s > beta} << D^(7/6 - beta), i.e. << H^(7/3 - 2 beta), better than the L^2 large-sieve
     count H^(4 - 4 beta) only for beta < 5/6. It bounds HOW MANY rows are bad, never WHETHER a given row is bad, and it is blind to
     multiplicity: the u = 1 row and its H^(1/6) copies are one L-function, which a density count over primitive characters counts once.
     The amplifier (copies) needs exactly the multiplicity count, and (0.1) shows every bounded-coefficient inequality is at least
     multiplicity x one member there.
(3d) Embedding in the full family (KNOWN in type: Bombieri-Vinogradov's large sieve inequality, Davenport ch. 28, FROM MEMORY; over K
     with Huxley's large sieve, FROM MEMORY). The sextic rows of conductor ~ U are a sub-family of all characters of conductor ~ U
     (size ~ U^2). Dropping the others by positivity, the full-family bound (D + D^(3/4) U^(5/4) + D^(1/2) U^2) D^eps (smooth form, my
     re-derivation with U_Vaughan = (D/U)^(1/2)) gives per-row average D/U + D^(3/4) U^(1/4) + D^(1/2) U, best D^(4/5) at U = D^(1/5),
     worse than (3b) for U > D^(1/5) (COMPUTED: 'fullfamily' lines). The sparse sextic sieve is the better tool; neither touches copies.

## 4. Answer to B10 (d) in one paragraph
Vaughan (or Heath-Brown) plus the sextic large sieve gives, at H = D^(1/2): Type I negligible on every non-copy row (smoothed
Polya-Vinogradov over O, U <= D^(1/4)); Type II needed on M in [D^(1/4), D^(1/2)]; in L^2 NO power saving over D^2 in any range
(PROVED, extremal vectors = conjugate characters of one row), and over all rows not even D^2 (copies, PROVED); in L^1 a saving D^(1/3)
per row on average for primitive rows (zero-density information), D for families of size <= D^(1/5). It never gives anything on the
copy rows, hence (0.2) no zero-free region. Dependence on sparsity: the full family of size U^2 at conductor U gives per-row D^(4/5)
at best; the sparse family's own sieve gives D^(2/3) at U = D^(1/2): sparsity HELPS the L^1 density statement (fewer, better spread
characters), and is irrelevant to the copies.

## 5. Impostor: the first false line (PROVED / KNOWN)
(5a) The identity (1b) holds for f_DH verbatim: c = 2 c_{<=U} - a * c_{<=U} * c_{<=U} + c * h * h, h supported on n > U. Type I with
     the smooth coefficient a_n (periodic mod 5, a combination of two characters) is as good as with 1 (Poisson again). So "no Vaughan
     identity" is FALSE; the identity is not where the Euler product enters.
(5b) FIRST FALSE LINE: the coefficient normalisation that every large-sieve and bilinear bound uses, ||beta||_2^2 << N^(1+eps)
     (|mu| <= 1; |g|, |mu*g| <= tau). KNOWN (Saias-Weingartner 2009, abstract and a citing summary read: a Dirichlet series with
     periodic coefficients has no zeros in Re s > 1 iff it is a Dirichlet polynomial times one L(s, chi)); f_DH = c L(s,chi) + conj c L(s, conj chi)
     is not of that form (FROM MEMORY, also Titchmarsh 10.25: f_DH has zeros in Re s > 1), so 1/f_DH has poles at some beta_1 > 1 and its
     Dirichlet series cannot converge right of them: sum_{n <= x} c_n is not O(x^(beta_1 - eps)), and |A_1^f(D)| >= D^(beta_1 - eps) > D along a
     sequence of D. The inverse coefficients are not bounded on average by any power of tau. Property used: complete multiplicativity of
     the Euler factors, through |1/L|'s coefficients mu(n) nu(n) of modulus <= 1 (equivalently: no zeros of L in Re s > 1, Euler product).
(5c) Consequence for the record (a QUESTION, posted, not an objection): SHORT_FAMILY 4(a) and N55 use the strip zero 0.808 + 85.7i as
     "the" pole of 1/f; if the rightmost poles have real part > 1, S^f >= D^(2 beta_1) > H D for every H < D^(2 beta_1 - 1), which includes
     part of the paper's own regime H = D^(1+theta). The impostor is then visible on BOTH sides, already at the normalisation.
     (Over K the analogous impostor c L_K(s,psi) + conj c L_K(s, conj psi) should behave the same: RISK, the Saias-Weingartner proof is over Q.)

## 6. The parity question
(6a) KNOWN, read (FI 1998, section 1). Hypotheses: level (R): sum_{d<=D} mu^2(d)|r_d(t)| <= A(x)(log x)^(-22) with x^(2/3) < D < x; bilinear
     (B): sum_m |sum_{N<n<=2N, mn<=x} gamma(n) mu(mn) a_mn| <= A(x)(log x)^(-22) for Delta^(-1) sqrt D < N < delta^(-1) sqrt x, gamma(n) = sum_{d|n,
     d<=C} mu(d), 1 <= C <= x/D. Theorem 1: sum_p a_p log p = H A(x)(1 + O(log delta/log Delta)). Quotes: "with (R) alone one cannot capture
     the primes, even for D(x) = x^(1-eps)"; "by narrowing this slightly to N > sqrt D we would not be able to break the parity problem";
     Selberg's example a_n = (1 + lambda(n))/2 "satisfies (R) with D = x^(1-eps) but fails to satisfy (B)"; "the source of cancellation in
     the bilinear form in (B) comes from the sign changes of the Moebius function mu(mn)". Note the conclusion's error term: at best
     O(log log x/log x). A parity-breaking input yields an asymptotic, never a power saving.
(6b) KNOWN, read (FI 2022, sections 1, 3, 10). "One gradually became aware of a general 'parity barrier'"; Siebert 1983 and Granville 2020:
     "a fixed improvement of the value of either F(s), f(s) [the Jurkat-Richert linear sieve functions] for any value of s, again in the
     case of arithmetic progressions and with x larger than a sufficiently large power of q, implies that exceptional zeros do not
     exist"; replacing 2 by 2 - eta in Brun-Titchmarsh for x > q^A(eta) "would lead to the banishment of exceptional zeros"; and section 10:
     "The exceptional character pretends to be the Moebius function on squarefree numbers". So the one precise known bridge between a
     parity-type improvement and zeros is: CONSTANT-factor improvement of a sharp sieve inequality at an arithmetic sequence =>
     no real zeros near s = 1. The extremisers of the linear sieve in APs are realised exactly by a character pretending to be mu.
(6c) MY ANSWER (labels per sentence). Is the short-family wall the parity problem in another guise?
     - PROVED (sections 2-3): at H = D^(1/2) the information a combinatorial decomposition can extract is: Type I complete (relative level
       D^(1/2), error O(D^-A) on non-copy rows), Type II empty in L^2 and of zero-density type in L^1. That is the classical parity
       situation (level information only), so in that sense YES: what is left is a quantity no level information can bound.
     - But the residual quantity is the copy row, A_1 itself, at POWER strength. HEURISTIC/KNOWN: parity is about o(1)-strength
       detection (Selberg's example is a main-term ambiguity of factor 0 versus 2); every parity-breaking input in the literature
       (FI 1998 (B); Heath-Brown x^3 + 2y^3 and Heath-Brown-Moroz, FROM MEMORY; Matomaki-Radziwill and Tao's logarithmic Chowla, FROM
       MEMORY) delivers asymptotics with log-power or o(1) relative error, with the main term supplied by a classical zero-free region
       (Hecke's PNT for the relevant field). None supplies a power saving at the trivial character, and none could without being a
       zero-free half-plane. So: NOT merely parity; it is "parity at the copy row, at power strength".
     - The right model is the SHAPE of (6b), one level up (HEURISTIC, my reading): a sharp general inequality (linear sieve; here the
       large sieve with copies) whose extremisers are a twist pretending to be mu (exceptional character; here the copy rows / trivial
       twist, SP-operator's N56); a fixed improvement at the arithmetic sequence excludes the bad zeros (constant factor => no Siegel
       zero; here power D^-delta => half-plane, SHORT_FAMILY 0a/0b). CONJECTURE (unsearched beyond the two FI papers): there is a
       Siebert-type theorem for the sextic family converting a CONSTANT-factor improvement of the copy-direction mean square at H < D
       into a de la Vallee Poussin-width zero-free region; testable as a statement, not computed.
(6d) Parity-breaking inputs available here.
     - Sextic family over Z[omega]: (i) the Gauss-sum identity gamma_2(n)^3 = mu(n) alpha(n) on squarefree n (QRH Lemma 4.1, via the
       digest; "the -1 at each prime IS mu") is a parity-SENSITIVE algebraic identity: it writes the sign (-1)^omega(n) as a cube of a
       theta coefficient. It is the paper's engine and enters only after Poisson in u, i.e. on the dual side (SHORT_FAMILY 3b): it is
       the one parity-breaking input in sight, and it acts in the long regime. (ii) Double oscillation of residue symbols
       (sum_{w,z} alpha_w beta_z (w/z)_6, the sextic large sieve itself; FROM MEMORY the engine of Heath-Brown-type and Koymans-Milovic
       spin Type II estimates): available over Z[omega], but in S(H,D) the bilinear variables enter as chi_m(u) chi_k(u), a TRILINEAR form in
       (u, m, k); Cauchy-Schwarz over u returns the mean square, and with an amplifier supported on copies the double-oscillation bound
       collapses to the trivial one (PROVED: on copies (w^6/m)_6 = 1, the sieve constant is M H^(1/6), not Delta). (iii) Nothing of FI (B) type
       (a Type II with mu(mn) in a narrow range around sqrt D) is known for this family, and by (6a) it would give only log savings.
     - t-family (Nyman-Beurling at bounded height): the family is finite-dimensional at fixed T (SP-operator 1d: effective rank about
       (T/pi) log N), so no averaging gain exists; the needed input is square-root cancellation of mu in intervals [k, k(1 + 1/T)] of length
       ~ k/T on average over k, i.e. a power-saving PNT in long intervals = RH-strength. Matomaki-Radziwill / Tao (FROM MEMORY) need
       T -> infinity (multiplicatively short intervals) and give o(1). Nothing available.

## 7. Outside my toolkit (for (d) of B2)

## 8. Ten-line summary
1. Vaughan's identity holds for ANY invertible Dirichlet series (algebra); for mu nu psi_u over Z[omega] it is Dunn's Prop. (read).
2. Type I at H = D^(1/2): negligible on every non-copy row once U <= D^(1/4) (smoothed Polya-Vinogradov over O; no Burgess).
3. Required Type II range: M in [D^(1/4), D^(1/2)], N = D/M (Heath-Brown identity gives the same range).
4. L^2 (S itself): the bilinear large sieve beats D^2 in NO range (PROVED: one row's conjugate characters attain D^2); over all rows the
   general norm is >= H^(1/6) D^2 (copies), so even S << D^2 for mu would be new (23/24).
5. L^1: saving D^(1/3) per primitive row on average at H = D^(1/2) (total D^(7/6), any a in [1/4,1/2]); total D for H <= D^(1/5).
6. That is zero-density information; it counts L-functions once, so it never reaches the copies and gives no zero-free region.
7. Impostor: the identity holds; the first false line is the coefficient normalisation (1/f_DH has poles in Re s > 1: Saias-Weingartner).
8. Parity: Type I complete + Type II empty = the parity situation; but the residue is A_1 at power strength, beyond parity:
   parity-breaking inputs (FI 1998, read) give log savings with an external main term.
9. Model: Siebert-Granville (FI 2022, read): fixed improvement of a sharp sieve at an arithmetic sequence excludes exceptional zeros;
   the wall is that shape one level up. The only parity-sensitive input here is gamma_2^3 = mu alpha, and it acts on the dual (long) side.
