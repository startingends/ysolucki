## (a) STRUCTURE
PROVED (seminar S1, B25; the finite folding identity is machine-checked, FORMAL B142). For phi on (0, L] and f_e(x) = phi(|x|),
f_o(x) = sgn(x) phi(|x|) on [-L, L]:
    Q_L(f_e) = 2 [ Q(phi) + H(phi) ],     Q_L(f_o) = 2 [ Q(phi) - H(phi) ],
 * Q(phi): the Weil form of phi alone; phi has support of length L, so this is the form on a window of HALF the size; it contains only the
   prime powers n <= e^L = sqrt(D);
 * H(phi): the Hankel (mirror) form of the full kernel on (0, L]:
     zeta:      H = E_+^2 - sum_{m>=1} E_m^2 - H_Lambda,   H_Lambda(phi) = sum_{n <= D} Lambda(n) n^(-1/2) (phi*phi)(log n),  D = e^(2L),
                E_+ = int phi e^(x/2) (pole; its e^(-x/2) half cancels the m = 0 Gamma square), E_m = int phi e^(-(2m+1/2)x);
     impostor:  H = - sum_{m>=0} E'_m^2 - H_c,             E'_m = int phi e^(-(2m+3/2)x) (Gamma((s+1)/2); no pole), H_c with its signed c(n).
