## #1 · Dial property = infinite divisibility (compound Poisson) of the scale distribution of theta^n; n=1,2 as isolated points of an ID-set
- status: open
- source: R2-free
- date: 2026-11-10
- tags: control,dial,B1,B11,create,unreviewed
- plain english: The dial (idea #12) is a knob n that turns zeta into other functions. The function at setting n lists in how many ways each whole number m is a sum of n squares; the formula for that count makes sense for fractional n too. Ask two things of each setting. First: are all the counts at least zero? Second, and stronger: read the counts as the odds in a lottery over whole numbers; can that lottery be produced by many small independent multiplicative steps? Functions built from primes in the way zeta is always can; that is what the prime product means. Example: at n = 1.4 the step that lands on 3 would need odds (2/3)(0.4)(-0.6) = -0.16, a negative chance, so the answer is no; and the first question already fails between 1 and 2, because the count for m = 3 is (4/3) n (n-1)(n-2), negative there: 3 is not a sum of two squares. Computed so far (exact fractions, one program, twenty minutes of work, checked by nobody): among settings up to 14 the second question is answered yes only at n = 1, 2 and 8; the first only at n = 0, 1, 2, 3, 4 and, as far as was looked, from about 4.16 on. The setting n = 8 is a warning: it passes both tests and is built from primes, yet its zeros are not on its centre line; and n = 4, also built from primes, fails the second test. So the test detects one particular kind of prime structure, not 'zeros on the line'. This is a fact about the family of impostors, not about zeta.
- wall: FAILS RULE: attacks no wall. It sharpens a control (the dial, #12) and tests the sign input of idea #10 along it. What it says about walls: on the dial, 'all prime-side couplings >= 0' (idea #10's sign fact) is the same as infinite divisibility of the scale law and holds only at isolated settings; one of them, n = 8, has its zeros off its centre line, so the sign property cannot by itself place zeros (the lesson of barrier B11, from a second example).
- new input: A probabilistic reading carried over from infinitely divisible laws and from Wishart / Gindikin theory on symmetric cones (the seat's analogy: a Wishart law with real shape parameter exists only for a discrete set of values plus a half-line, the Wallach set). Two sets: M = {n > 0 : every Dirichlet-logarithm coefficient c_n(m) of sum a_n(m) m^-s is >= 0}, a_n = r_n/(2n), i.e. the scale law is compound Poisson; and S = {n >= 0 : r_n(m) >= 0 for all m}, 'the Wallach set of theta'. Neither is in the dial entries #12, #13, which have only the single coupling at m = 3.
- claim: (1) PROVED by hand and rechecked by machine (seat): c_n(2) = n-1, c_n(3) = (2/3)(n-1)(n-2), c_n(4) = 1 + (1/3)(n-1)(n-2)(n-3) - (n-1)^2/2; r_n(2) = 2n(n-1) < 0 on (0,1), r_n(3) = (4/3)n(n-1)(n-2) < 0 on (1,2), r_n(7) = 64 C(n,4) + 128 C(n,7) < 0 on (2,3). Hence S meets [0,3) in {0, 1, 2} and M meets (0,2] in {1, 2}. (2) COMPUTED (exact rational arithmetic, one implementation, never rechecked), on the grid n = k/8: M meets (0, 14] in {1, 2, 8} (m up to 1200; first failures at m = 7 or 4 for n between 2 and 4.75, at m = 6 up to 8, then at m = 12, 18, 24, 30, 36, 60, 120 and on to 420); n = 8 is in M because its series is, up to a constant, (1 - 2^(1-s) + 4^(2-s)) zeta(s) zeta(s-3). S: every sampled n in (3, 4) fails (at m = 23, 28, 16, 64 or 256), n in (4, 4.141] fails at m = 512, and no negative coefficient was found for n from 4.156 to 30 (m up to 600). CONJECTURES (seat): M is discrete with 1 and 2 isolated; S is {0, 1, 2, 3, 4} together with a half-line starting at some n0 in (4.14, 4.6).
- prediction: Blind, written 23:12 UTC before any computation (seat's PROGRESS.md; order checked by nobody). P1 'S = {0,1,2} and everything from 3 on' (guessed from the Wishart pattern and Lagrange's four squares): MISS, negatives throughout (3,4) and just above 4. Seat's reason: sparse values of the integer members (r_3(4^k) = 6, r_4(2^k) = 24 stay bounded) drag the neighbouring real members below zero. Controls: the dial at n = 1.4 fails at m = 3 with c = -0.16 (exact); the Davenport-Heilbronn impostor already has coefficients of both signs. Registered and NOT yet computed: P3, n0 in (4.14, 4.6) with every failure just above 4 at a power of 2; P4, for integer n = 15 to 30 the first failing m is highly composite and below 60000 (n = 16: between 1260 and 1680).

## #2 · Wallach set of theta: for which REAL n does theta^n have all coefficients >= 0? (carried from Wishart/Gindikin theory on symmetric cones)
- status: open
- source: R2-free
- date: 2026-11-10
- plain english: A Wishart law with real shape n exists only for n in {0,1,..,r-1} or n > r-1. Same question for sums of n squares: r_n(2)=2n(n-1)<0 for 0<n<1 because 2 is not a square; r_n(3)<0 on (1,2) because 3 is not a sum of two squares; r_n(7)<0 on (2,3) because 7 is not a sum of three. Guess: {0,1,2} then everything from 3 on (Lagrange).
